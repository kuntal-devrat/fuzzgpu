# Security Policy

## Supported Versions

Security updates are applied to the latest stable minor release of `fuzzgpu`.

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in `fuzzgpu`, please report it responsibly:

- **Do NOT open a public issue** on GitHub.
- Use GitHub's private security advisory reporting feature under the **Security** tab of the repository, or contact the maintainer directly.
- Include a detailed description of the vulnerability, steps to reproduce, and any proof-of-concept code.
- You should receive an acknowledgment within 48 hours, followed by updates on the fix and coordinated disclosure timeline.
